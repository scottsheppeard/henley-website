# Existing-site imagery (thehenley.com.au WordPress uploads)

Inventory taken 2026-09-10, read-only, from `/mnt/persistent/prod/www_henleycomau/wp-content/uploads/`. WordPress-generated size variants (`-WIDTHxHEIGHT`) were ignored; `-scaled` (2560px) variants are listed in the full inventory but the unscaled original was copied. Of 237 originals, 132 are logo/brand files under `branding/` (see below), 105 are photos or graphics, and **53 were copied here** for review. Contact sheets of every original are in `_contact-sheets/` (`sheet-1..3.jpg`; `detail-A..D.jpg` are larger views of the candidates).

Page references were found by filename match in `source/live-capture-2026-09-09/pages/*.html` (img/srcset, `og:image`, Elementor `data-settings` backgrounds) and in the Elementor per-page CSS (`css-bg` = CSS `background-image` in `uploads/elementor/css/post-<id>.css`, mapped to the page by the page's body id). A trailing `*` means the page references the `-scaled` 2560px copy of that original.

Licence legend: **Henley** = shot for The Henley (no external mark found); **identifiable** = residents/staff recognisable — check consent before reuse on a new site; **stock/likely stock** = do not reuse without confirming the licence covers the new site.
