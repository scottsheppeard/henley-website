# Live site capture — thehenley.com.au, 9 September 2026

A read-only snapshot of the **WordPress site as published on 9 September 2026**,
taken before any rebuild work began. It is the migration source for the new
Astro site: page and post copy, headings, link targets, image URLs and meta tags
are extracted from here rather than re-fetched, so the content we migrate is
pinned to a known state and the build does not depend on the old site staying up.

Captured by an earlier session into its scratchpad and moved into the repo on
2026-09-09 so it survives `/tmp` cleanup.

## Contents

| Path | What it is |
|---|---|
| `sitemap.txt` | The two Yoast sitemaps flattened — 11 `page` URLs and 16 `post` URLs (15 articles plus the `/news/` index), each with its WordPress `lastmod`. 27 URLs total. |
| `pages/*.html` | Raw served HTML for each of those 27 URLs, one file per URL, named for the slug (`home.html` is `/`). Includes the Elementor markup, Yoast meta and JSON-LD, and the `rel=shortlink` id used to build the `/?p=<id>` redirect map. |
| `text/*.txt` | The same 27 pages rendered to readable text — headings, body copy, link labels in `[brackets]`, images as `[img <url> \| alt=…]`. The practical source for migrating copy; use the HTML when markup or metadata matters. |

## Not captured here

Media binaries. The ~254 uploads still live on the production host at
`/mnt/persistent/prod/www_henleycomau/wp-content/uploads/`; images chosen for the
new site are re-encoded from there (or from the brand kit) into `src/`, and the
audited legacy asset copy is assembled separately under `deploy/`.

## Rules

Treat this tree as **immutable**. Do not edit, reformat or "fix" these files —
their value is being exactly what the old site served. Corrections belong in the
migrated content under `src/content/`. Anything derived from this capture
(the URL manifest, the exported Markdown) is generated by a committed script so
the derivation stays reproducible and reviewable.
